## Project Overview
The CSOPESY Desktop-Style OS Emulator is a simulated desktop environment developed using C++, GLFW, OpenGL, and Dear ImGui. It demonstrates a basic desktop interface with a boot screen, wallpaper, taskbar, clock, and application windows.

## Features
### Boot Screen
Displays the CSOPESY title, developer names, version date, and loading message for approximately three seconds.
### Desktop Wallpaper
Displays a blue gradient sky, green hills, and the CSOPESY OS v1.0 label.
### Live Clock
Shows the current system date and time at the top-right corner.
### Taskbar
Displays the Task Manager and PWR buttons at the bottom of the desktop.
### Task Manager
Displays sample process names, CPU usage, and memory usage.
### File Explorer
Provides a simulated interface with common folders such as Desktop, Documents, Downloads, Pictures, and This PC.
### Applications Window
Displays information about the emulator and provides buttons to open File Explorer and Task Manager.
### Power Button
Closes the emulator when clicked.

## How to Run

### Step 1: Open the Project
Open the project in Visual Studio 2026.
### Step 2: Configure the Source Files
Ensure `CSOPESY-M04.cpp`, the Dear ImGui source files, and the required GLFW files are included or configured in the project.
### Step 3: Configure the Libraries
Set the C++ include directories and library directories in the project properties. Link the required GLFW and OpenGL libraries.
### Step 4: Build the Project
Select **Build > Build Solution**
